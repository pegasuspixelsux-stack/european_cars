# Apple Design

## Rules
- Font stack: `-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", "Segoe UI", system-ui, sans-serif`.
- Maintain high-contrast, readable text (WCAG AA minimum); clear size steps between title, headline, body, caption.
- Use a precise spacing scale (4/8/12/16/24/32/48/64) and generous whitespace.
- Translucent materials: `backdrop-filter: blur(20px) saturate(180%)` with subtle borders; use sparingly for nav bars, sheets, overlays.
- Consistent corner radii, immaculate alignment, one primary action per view.
- Icons: consistent stroke weight and optical size (SF Symbols style).
- Support light and dark appearances.
