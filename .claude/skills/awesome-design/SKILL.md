# Awesome Design

## Rules
- Use bold section contrast (dark/light alternation, full-bleed color fields).
- Give asymmetric breathing room: offset grids, oversized margins, intentional negative space.
- Frame photography editorially: large crops, consistent aspect ratios, captions, overlap with type.
- Use kinetic typography sparingly: oversized headlines, scroll-linked reveals, marquee accents.
- Provide one high-impact visual anchor per section.
- Tell the brand story through sequence: hook, proof, detail, call to action.
- Keep performance and accessibility intact (reduced motion, optimized media).
