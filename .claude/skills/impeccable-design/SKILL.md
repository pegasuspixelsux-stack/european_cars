# Impeccable Design

## Rules
- Build a bespoke, harmonized palette (a considered neutral ramp plus one or two accents); no default AI-purple/blue gradients.
- Pair typefaces deliberately (display + text), with intentional scale, tracking, and leading.
- No repetitive identical card grids; vary scale, span, and emphasis editorially.
- No unstyled browser defaults (buttons, inputs, scrollbars, focus, selection).
- Maintain a consistent layout rhythm: vertical spacing scale, alignment to a grid, deliberate asymmetry.
- Every section needs a purpose and a focal point; remove filler copy and decorative noise.
- Review before finishing: if it looks like a template, redo it.
