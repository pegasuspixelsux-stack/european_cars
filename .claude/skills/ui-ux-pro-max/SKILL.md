# UI/UX Pro Max

## Rules
- Design friction-free journeys: fewest steps to goal, clear next action on every screen.
- Premium visual pacing: consistent spacing rhythm, strong hierarchy, restrained palette.
- Clear, singular primary CTAs with strong contrast; secondary actions visually subordinate.
- Handle every state: loading (skeletons), empty, error, success, disabled.
- Accessible contrast (WCAG AA), focus visibility, touch targets of at least 44px.
- Responsive from 375px up; verify before finishing.
